ПЕРВЫЙ ТУЛЬСКИЙ — СЕРВЕР ДЛЯ PROXMOX LXC 1.1.0
================================================

Изменения 1.1.0
---------------
- Добавлено управление системной громкостью телевизора.
- Работают кнопки Громкость +, Громкость - и Mute.
- Версия приложения Samsung повышена до 1.2 для автоматического обновления.

Назначение
----------
Сервер работает постоянно внутри Debian/Ubuntu LXC, находит актуальный адрес
прямой трансляции и передаёт его приложению Samsung Legacy/Orsay.
Обычный компьютер после этого не нужен.

Рекомендуемый контейнер
-----------------------
- Debian 12 или новее;
- непривилегированный LXC подходит;
- 1 ядро, 256–512 МБ памяти, 2 ГБ диска;
- сетевой мост vmbr0;
- постоянный IPv4 в одной локальной сети с телевизором;
- включённый автозапуск контейнера в Proxmox.

Установка
---------
1. Скопируйте и распакуйте архив внутри LXC.
2. Перейдите в распакованную папку.
3. От имени root выполните:

   bash install.sh

Установщик автоматически определит IPv4, установит Python 3, создаст отдельного
системного пользователя, установит службу и включит её автозапуск.

Чтобы явно указать адрес:

   FIRST_TULA_IP=192.168.1.50 bash install.sh

Используйте реальный постоянный адрес вашего LXC.

Проверка
--------
Откройте на телефоне или компьютере:

   http://АДРЕС_LXC/health

Ответ должен быть: ok

Полезные команды
----------------
Состояние:
   systemctl status first-tula-tv --no-pager

Журнал в реальном времени:
   journalctl -u first-tula-tv -f

Перезапуск:
   systemctl restart first-tula-tv

Повторная установка/обновление:
   bash install.sh

Настройка телевизора
--------------------
Если приложению ранее был записан адрес старого компьютера, есть два варианта:

1. Назначить LXC прежний адрес компьютера. Старое устройство с этим адресом
   должно быть выключено или переведено на другой IP. App Sync не нужен.

2. Оставить LXC новый адрес и один раз выполнить App Sync на телевизоре,
   указав IP контейнера. После этого компьютер больше не требуется.

Сеть и безопасность
-------------------
- Телевизор должен иметь доступ к TCP-порту 80 контейнера.
- Если включён Proxmox Firewall, разрешите входящий TCP 80 из домашней сети.
- Контейнеру нужен исходящий доступ в интернет по HTTP/HTTPS и работающий DNS.
- Не пробрасывайте TCP 80 этого контейнера на внешнюю сторону роутера.
- IP контейнера должен оставаться постоянным.

Файлы после установки
---------------------
Программа: /opt/first-tula-tv
Настройки: /etc/first-tula-tv.conf
Служба:    /etc/systemd/system/first-tula-tv.service
