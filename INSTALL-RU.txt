УСТАНОВКА FIRST TULA LIVE 1.1.1 НА SAMSUNG UE32F4500 (F-СЕРИЯ, 2013)

1. Распакуйте весь архив в одну папку на компьютере Windows.
2. Компьютер и телевизор подключите к одному роутеру.
3. Дважды щёлкните START-SERVER.cmd и подтвердите запрос Windows.
4. Если показано несколько IP-адресов, выберите адрес домашней сети.
5. Оставьте окно сервера открытым.
6. На телевизоре войдите в Samsung Account под именем develop.
7. Откройте Smart Hub -> Доп. приложения -> Парам. -> IP Setting.
8. Введите IP-адрес, показанный в окне сервера.
9. Откройте Парам. ещё раз и выберите Start App Sync.
10. После завершения найдите FirstTulaLive среди приложений и запустите.
11. Не закрывайте окно сервера во время просмотра: компьютер получает
    временный адрес эфира по современному HTTPS для старого телевизора.

Если IP Setting не отображается, убедитесь, что выполнен вход под develop.
Если синхронизация не начинается, разрешите PowerShell доступ в частной сети
в брандмауэре Windows и повторите Start App Sync.

Важно: синхронизация может удалить другие пользовательские виджеты,
установленные ранее с другого локального сервера.

Если меняется IP-адрес компьютера, повторите Start App Sync, чтобы приложение
получило новый адрес локального сервера.

Сервер создаёт правило брандмауэра "FirstTula TV Server", разрешающее доступ
к TCP-порту 80 только устройствам локальной сети.

Чтобы остановить сервер, нажмите Ctrl+C или закройте его окно.
